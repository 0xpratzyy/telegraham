# Archive

Dated records of past experiments: benchmark sheets, eval matrices,
model-swap results, and QA session notes. Kept for provenance — **they
describe the system as it was on their date, not current behavior.**

Several of these reference engines retired in the July 2026 architecture
cleanup (agentic reply-queue triage, dashboard task triage/extraction). For
the current system, read [../architecture.md](../architecture.md) and
[../query-engine-matrix.md](../query-engine-matrix.md).
