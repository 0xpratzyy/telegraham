# Dev Workflow Notes

- Before major milestone pushes or broad launcher/search changes, run an independent subagent audit on the affected code slice and review the findings before pushing.
- Update the core docs with every meaningful commit that changes product scope, engine behavior, storage semantics, or architectural direction.
- Keep [product-prd.md](product-prd.md), [task-tracker.md](task-tracker.md), [architecture.md](architecture.md), and [query-engine-matrix.md](query-engine-matrix.md) in sync with shipped behavior.
- Active work items live in GitHub issues, not in-repo trackers.
